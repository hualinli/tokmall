# TokMall 文档导航

本目录各文档按用途维护。第一次接触项目，先看 [根 README](../README.md) 的使用场景和演示路线，再选择下面的入口。

## 推荐阅读路线

| 你想做什么 | 阅读顺序 |
|---|---|
| 看懂项目在干什么 | 根 README → 商城业务 → 后端架构 |
| 本地运行与演示 | 根 README 的启动/演示步骤 → 开发与运维 → web README |
| 理解交易正确性 | 商城业务 → 商城技术设计 → 相关 ADR → 订单/券/对账测试 |
| 学习压测和排障 | 性能证据的最近实验 → 开发与运维的压测/动态排障 → 诊断原始文件 |
| 准备面试 | 面试清单的第一轮基础题 → 对应实现与测试 → 第二轮追问和实验练习 |
| 修改项目 | AGENTS.md → 对应技术文档 → 源码与测试 |

## 如何核对事实

运行时装配看 [main.go](../cmd/api/main.go)，接口看 [OpenAPI](../internal/api/openapi.yaml)，数据库结构看 [迁移](../migrations/)，默认配置看 [config.go](../internal/config/config.go)，命令看 [Makefile](../Makefile)。文档中的能力需要能指到实现或测试。

性能结果按测量日期和构建版本阅读，不把旧版本或诊断变体的数字套到当前实现。真实依赖测试需要显式开关；故障演练脚本、模拟媒体和真实存储测试的覆盖不同。具体限制保留在对应运行指南与实验归档中。

文档沿用上述入口，不另建里程碑流水账或重复面试笔记。新的实现取舍写入 ADR，业务规则更新商城业务，测量证据更新性能文档，未完成工作更新 roadmap。
